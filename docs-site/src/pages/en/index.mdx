# KnotRoute, without the pain

KnotRoute is a self-hosted encrypted service overlay with `.knot` identities, multi-hop routing, hidden-service rendezvous and embeddable clients.

<Cards>
  <Card href="/en/client/windows" title="Open a .knot site">Install the desktop client, enable `.knot` integration and trust the local CA.</Card>
  <Card href="/en/client/android" title="Connect from Android">Network profiles, deep links, embedded browser and local CA.</Card>
  <Card href="/en/self-hosted/docker" title="Publish a Docker service">Run a sidecar next to an existing application without exposing its private port.</Card>
  <Card href="/en/self-hosted/overview" title="Deploy your own network">Network ID, multiple Beacons, relays, Control and Agents.</Card>
</Cards>

Control is a management plane only. The overlay, Beacons, relays and services continue to operate when Control is offline.
