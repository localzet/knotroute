# Publish a Docker service

```yaml
services:
  app:
    image: example/app:latest
    networks: [private]
  knotroute:
    image: ghcr.io/localzet/knotroute-sidecar:latest
    networks: [private]
    volumes: [knotroute-data:/data]
    environment:
      KNOTROUTE_NETWORK_ID: "kn_..."
      KNOTROUTE_BEACONS: "https://beacon-a.example,https://beacon-b.example"
      KNOTROUTE_SERVICE_NAME: "web"
      KNOTROUTE_SERVICE_TARGET: "app:8080"
volumes:
  knotroute-data:
```

Persist `/data`; it holds the service identity that determines the stable `.knot` address.
