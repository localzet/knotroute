# KnotRoute без боли

KnotRoute — self-hosted encrypted overlay для сервисов с собственными `.knot`-идентичностями, multi-hop routing и embedded-клиентами.

<Callout>Начинайте не с протокола, а с задачи. Для обычного пользователя нужен клиент и профиль сети; для сайта — sidecar; для инфраструктуры — Beacon/relay; Control нужен только для удобства управления.</Callout>

## Что относится к data plane

`knotroute`, Beacon relay, обычные relays, sidecars, circuits, directory и rendezvous. Они продолжают работать без Control.

## Что относится к management plane

`knotroute-control` и `knotroute-agent`. Они нужны для inventory, deployment jobs, onboarding, мониторинга и обновлений, но не маршрутизируют пользовательский трафик.
