# Beacon и relays

Beacon — soft-state discovery, а не центральная база сервисов. Он принимает подписанные node announcements и отдаёт candidate peers.

```yaml
services:
  beacon:
    image: ghcr.io/localzet/knotroute-beacon:latest
    restart: unless-stopped
    ports:
      - "7447:7447"
    environment:
      KNOTROUTE_NETWORK_ID: "kn_..."
      KNOTROUTE_BEACON_LISTEN: "0.0.0.0:8080"
      KNOTROUTE_BEACON_RELAY: "true"
      KNOTROUTE_BEACON_RELAY_LISTEN: "0.0.0.0:7447"
      KNOTROUTE_BEACON_RELAY_ADVERTISE: "relay-a.example.net:7447"
```

HTTP discovery обычно публикуется через Traefik/Caddy как HTTPS. `7447/tcp` — сырой KnotRoute transport.
