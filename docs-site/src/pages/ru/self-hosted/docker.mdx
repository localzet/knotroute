# Публикация Docker-сервиса

Допустим приложение доступно внутри Docker network как `app:8080`.

```yaml
services:
  app:
    image: example/app:latest
    networks: [private]

  knotroute:
    image: ghcr.io/localzet/knotroute-sidecar:latest
    restart: unless-stopped
    networks: [private]
    volumes:
      - knotroute-data:/data
    environment:
      KNOTROUTE_NETWORK_ID: "kn_..."
      KNOTROUTE_BEACONS: "https://beacon-a.example,https://beacon-b.example"
      KNOTROUTE_SERVICE_NAME: "web"
      KNOTROUTE_SERVICE_TARGET: "app:8080"

networks:
  private:

volumes:
  knotroute-data:
```

Не публикуйте `app:8080` на host, если сервис нужен только через KnotRoute.

<Callout type="warning">Не удаляйте persistent `/data`: там лежит service identity. Потеря identity означает новый canonical `.knot` address.</Callout>
